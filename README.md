AI-Based Employee Performance Prediction System

1. Introduction

The AI-Based Employee Performance Prediction System is a Python-based project that uses Machine Learning to analyze employee performance based on attendance, productivity, and task completion.

It helps understand employee performance and classify employees into different performance categories.

2. Objectives

- To predict employee performance using Machine Learning.
- To analyze employee attendance and productivity.
- To classify employees as High, Average, or Low performers.
- To maintain and manage employee records.

3. Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

4. Main Features

- View employee records.
- Add new employee records.
- Edit existing employee records.
- Delete employee records.
- Calculate average performance scores.
- Predict employee performance categories.
- Display employee information through a web interface.

5. Performance Categories

The system uses three performance categories:

- High
- Average
- Low

6. Project Files

- "app.py" – Main Streamlit application.
- "employee_training_data.csv" – Sample employee training dataset.
- "employee_records.csv" – Employee records.
- "employee_model.pkl" – Saved machine learning model.

7. How to Run the Project

1. Install Python.

2. Install the required Python libraries.

3. Open the project folder.

4. Run the following command in the terminal:
   
   "streamlit run app.py"

5. Open the local address displayed in the terminal in your web browser.

8. Dataset Information

The project uses sample, artificially generated employee data for demonstration and model training.

9. Future Scope

- Improve prediction accuracy using larger and more representative datasets.
- Add employee performance reports.
- Include more employee performance factors.
- Improve the user interface.

10. Conclusion

This project demonstrates how Python and Machine Learning can be used to analyze employee performance and support performance management.
